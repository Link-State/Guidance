1번 : quota
2번 : edquota
3번 : setquota
4번 : repquota
정답 : 8
해설 : 2. edquota : 사용자와 그룹에 대해 쿼터를 설정하고 변경하는 명령어3. setquota : 터미널에서 직접 사용자나 그룹에 쿼터를 적용하는 명령어4. repquota : 터미널에서 직접 사용자나 그룹에 적용된 쿼터(디스크 사용량, 적용 내용)를 요약하여 출력하는 명령어[개념 보충 _ 쿼터 관련 명령어]1) quotaon : 쿼터를 활성화하는 명령어2) quotaoff : 파일시스템에 적용된 쿼터의 사용을 중지하는 명령어3) quotacheck : 모든 파일 시스템을 점검하고, 쿼터 설정 및 기록 파일 갱신하는 명령어[개념 보충 _ 쿼터를 설정하는 과정]quotacheck → edquota → quotaon → repquota<#nbsp;>[해설작성자 : JSC]<#nbsp;><#nbsp;>repquota는 특정 파일 시스템(/home)에서 모든 사용자의 쿼터 정보를 확인하는 명령어quota는 특정 사용자에 대한 정보를 확인하는 명령어<#nbsp;>[해설작성자 : 오늘 ㅅㅣ험]<#nbsp;><#nbsp;>
