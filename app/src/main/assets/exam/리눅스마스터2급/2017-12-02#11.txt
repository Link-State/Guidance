문제지문 : 다음 중 사용중인 셸을 bash 로 변경하는 명령으로 틀린 것은?
사진 : 
1번 : chsh
2번 : chsh -s bash
3번 : chsh -s /bin/bash
4번 : chsh --shell /bin/bash
정답 : 2
해설 : chsh : change shell 셸 변경-s 옵션 : 셸 지정 - 지정하는 셸로 변경.정답 2번.-> 모오든 셸들은 /bin 안에 있습니다..거기가 걔네 집(?)이에요. 지금 2번은 집잃은 어린셸입니다.--shell 입니다.chsh --shell 입니다.-s 와 --shell이랑 같습니다.맞습니다.<#nbsp;>[해설작성자 : 이번주 시험]<#nbsp;><#nbsp;>
