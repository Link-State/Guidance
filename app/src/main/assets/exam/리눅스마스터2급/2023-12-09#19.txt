문제지문 : 다음 중 nano 편집기에서 현재 커서가 위치한 줄의 처음으로 이동할 때 사용하는 키 조합으로 알맞은 것은?
사진 : 
1번 : [Ctrl]+[a]
2번 : [Ctrl]+[e]
3번 : [Ctrl]+[o]
4번 : [Ctrl]+[i]
정답 : 1
해설 : [Ctrl]+[a]: 현재 행의 시작 부분으로 커서를 이동[Ctrl]+[e]: 현재 행의 끝 부분으로 커서를 이동[Ctrl]+[o]: 파일을 저장하고 나가기 위해 사용 (저장: Write Out)[Ctrl]+[i]: 탭을 삽입합니다..(탭: Insert Tab)<#nbsp;>[해설작성자 : 합격 ㄱ]<#nbsp;><#nbsp;>달아주신 문제 해설 중 헷갈리는 부분이 있어 작성합니다..저만 헷갈렸는지 모르겠지만,저는 '[Ctrl]+[o]: 파일을 저장하고 나가기 위해 사용 (저장: Write Out)'라는 문장을 보고[Ctrl]+[o]가 vi에서 ':wq'(Write and Quit)와 같은 '저장하고 나가기'역할을 하는 것으로 이해했으나 그렇지 않습니다.[Ctrl]+[o]는 파일 저장만을 수행합니다..(Write 'Out'에서 'Out'은 나가기를 의미하는 것이 아닙니다..'Write Out'이 곧 'Save'를 의미하는 것입니다.)'나가기'를 하기 위해서는 [Ctrl]+[x]를 눌러야 합니다..[Ctrl]+[x] (Exit)를 누르면 저장하지 않은 경우 저장 여부를 묻고, 사용자가 Yes나 No를 누르면 나갈 수 있게 됩니다.[Ctrl]+[o]를 누르면 'File Name to Write'의 입력으로 파일명을 입력 후 엔터를 누르면 여전히 nano editor 내부에 남아 있습니다.<#nbsp;>[해설작성자 : 모두화이팅]<#nbsp;><#nbsp;>
