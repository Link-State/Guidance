문제지문 : 다음은 $HOME/.vimrc 파일의 설정 내용이다. 다음 중 설정에 대한 설명으로 틀린 것은?
사진 : <!PICTURE@image18>
1번 : 행의 앞에 행번호를 표시 기능이 켜져 있다.
2번 : 탭의 크기를 4로 설정한다.
3번 : 자동들여쓰기 기능이 켜져 있다.
4번 : 매크로가 선언되어 있고 기능이 켜져 있다.
정답 : 4
해설 : 1. set nu : 행의 앞에 행번호를 표시 기능이 커져 있다.2. set no ai : 자동들여쓰기 기능을 끈다.3. set ts=4 : 탭의 크기를 4로 설정한다.4. map q :wq! : q를 입력하면 :wq! 를 입력한 것과 같은 매크로를 선언한다.<#nbsp;>[해설작성자 : 황상연]<#nbsp;><#nbsp;>
