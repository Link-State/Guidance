문제지문 : 다음 결과에 해당하는 명령으로 알맞은 것은?
사진 : <!PICTURE@image21>
1번 : rpm -ql vsftpd
2번 : rpm -qa vsftpd
3번 : rpm -qV vsftpd
4번 : rpm -qip vsftpd-3.0.2-29.el7_9.x86_64.rpm
정답 : 8
해설 : [질의(query)모드]rpm -ql~~~ : 패키지가 설치한 설치한 파일목록을 출력.rpm -qa : 시스템에 설치된 모든 패키지 정보를 출력.rpm -qip~~~.rpm : 패키지 파일에 대한 정보를 출력.[검증(Verify)모드]rpm -qV~~~ : 패키지를 검증한다.<#nbsp;>[해설작성자 : comcbt.com 이용자]<#nbsp;><#nbsp;>문제에서 , Install Date: (not installed) 가 핵심 힌트로서,&#8226; -ql → 파일 목록&#8226; -qa → 설치된 패키지 검색&#8226; -qV → 무결성 검증&#8226; -qip → 설치 안 된 rpm 파일 정보 조회따라서 제시된 출력(Install Date: (not installed) 포함)은 rpm -qip 명령의 결과입니다.<#nbsp;>[해설작성자 : 박강호]<#nbsp;><#nbsp;>
