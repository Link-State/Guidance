문제지문 : 다음 중 10GB 용량을 가진 디스크 4개를 사용해서 RAID-0 을 구성했을 경우 실제 사용 가능한 디스크 용량으로 알맞은 것은?
사진 : 
1번 : 10GB
2번 : 20GB
3번 : 30GB
4번 : 40GB
정답 : 8
해설 : 10GB 디스크 4개 사용 시 각 RAID에 대한 설명.RAID-0 : 스트라이핑의 경우 용량 모두 사용 40GB.RAID-1 : 미러링의 경우 절반으로 줄어듦 20GB.RAID-5 : 1개의 디스크 패리티로 사용 30GB.RAID-6 : 2개의 디스크 패리티로 사용 20GB.<#nbsp;>[해설작성자 : 빠대비]<#nbsp;><#nbsp;>RAID-0(Striping): RAID-0 은 데이터 스트라이핑을 사용하여 여러 디스크에 데이터를 나누어 저장. 하나의 디스크가 손상되면 모든 데이터 손실: 사용가능한 용량 : 10 GB * 4 = 40 GBRAID-1 (Mirroring):RAID-1 이 데이터를 모든 디스크에 동일하게 복사하여 저장. 데이터 보호 뛰어남, 저장 용량 비효율적: 사용가능한 용량  : 10GB (모든 디스크에 동일한 데이터가 저장)RAID - 5(Strinping with Parity): 스트라이핑과 함꼐 패리티 정보를 사용.: (N-1) * 10 GB = 30GBRAID-6 (Striping with Double Parity): 두개의 패리티 사용: (n-2) * 10 GB = 20GB<#nbsp;>[해설작성자 : 이겁니다!이거에요]<#nbsp;><#nbsp;>
