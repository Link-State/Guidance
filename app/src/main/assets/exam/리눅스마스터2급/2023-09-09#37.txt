문제지문 : 다음 중 Makefile 파일이 생성되는 소스 설치 단계로 알맞은 것은?
사진 : 
1번 : configure
2번 : make
3번 : cmake
4번 : make install
정답 : 1
해설 : 소스 파일을 이용한 설치 단계: configure → make → make installconfigure : Makefile 생성을 위한 스크립트make : 소스를 컴파일make install : 설치를 하는 과정<#nbsp;>[해설작성자 : 5일벼락치기]<#nbsp;><#nbsp;>
