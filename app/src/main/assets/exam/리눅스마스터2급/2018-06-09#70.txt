문제지문 : 다음 중 로컬 네트워크에 있는 다른 시스템의 맥(MAC) 주소를 확인할 때 사용하는 명령으로 알맞은 것은?
사진 : 
1번 : ip
2번 : ss
3번 : arp
4번 : ifconfig
정답 : 4
해설 : arp : 네트워크에 등록된 하드웨어주소를 확인할 수 있다..Ip주소와 MAC주소 확인 가능.ss : netstat의 대체로 네트워크 상태를 확인할 수 있다.ifconfig : 네트워크 인터페이스 구성을 위한 설정 또는 확인 가능.ip : ip주소와 특성 정보, 네트워크 상태, 라우팅 테이블, 멀티캐스트, ARP 테이블 등 확인 가능.<#nbsp;>[해설작성자 : ㄱㅣㅁ대웅]<#nbsp;><#nbsp;>ifconfig 는 자신의 MAC 주소를 확인 가능하고apr 는 자신을 제외한 다른 호스트들의 MAC 주소를 확인한다.<#nbsp;>[해설작성자 : 024]<#nbsp;><#nbsp;>
