문제지문 : 다음 설명에 해당하는 프로토콜로 알맞은 것은?
사진 : <!PICTURE@image30>
1번 : IP
2번 : VRRP
3번 : TCP
4번 : UDP
정답 : 8
해설 : [TCP].프로토콜 연결 수립- 연결지향형- 3-way handshaking 연결 방식.신뢰성- 전송을 신뢰할 수 있다..전송속도- 빠르지만 UDP보다 느림. 부하- 낮지만 UDP보다 높은. 기타- 패킷들의 전송흐름을 제어[UDP].프로토콜 연결 수립- 비 연결형.신뢰성- 전송을 신뢰할 수 없다..전송속도- 매우 빠르다. 부하- 매우 낮음. 기타- IP[IP]- 인터넷을 구성하는 핵심요소- 인터넷 전송단위인 Datagram 정의- 인터넷 주소체계 정의- 네트워크 계층과 전송 계층 사이의 데이터 이동[VRRP](Virtual Redundancy Router Protocol)- VRRP는 RFC Standard 문서에 정의된 표준입니다..  HSRP와 다르게 Cisco 뿐만 아니라, 모든 Vendor에서도 지원되는 Protocol 입니다.<#nbsp;>[해설작성자 : 이번주]<#nbsp;><#nbsp;>
