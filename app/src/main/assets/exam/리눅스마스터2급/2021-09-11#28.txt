기출연도 : 2021-09-11
과목 : 1
문제번호 : 28
문제지문 : 다음 중 현재 로그인에서 사용 중인 셸의 우선 순위 항목값인 NI 및 PRI 값을 확인할 때 사용하는 명령으로 알맞은 것은?
사진 : 
1번 : nice
2번 : renice
3번 : ps
4번 : kill
정답 : 4
해설 : 1) nice : 프로세스 사이의 우선순위를 확인하고 우선순위를 변경할수 있는 명령2) renice : 이미 실행중인 프로세스의 우선순위를 변경할수 있다..기존 NI값에 상관없이 NI값을 설정3) ps : 실행중인 프로세스 상태를 보여줌4) kill : 프로세스를 종료 시킴
