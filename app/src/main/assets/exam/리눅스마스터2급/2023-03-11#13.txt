문제지문 : 다음 중 이용할 수 있는 셸의 정보를 확인할 때 사용하는 명령으로 알맞은 것은?
사진 : 
1번 : chsh -i
2번 : chsh -s
3번 : chsh -u
4번 : chsh -l
정답 : 8
해설 : chsh: 일반 사용자 환경에서 셸 변경chsh -l : 파일안의 지정된 셀들을 나열, 시스템에서 사용 가능한 셸목록을 확인하는 명령어<#nbsp;>[해설작성자 : dinnet]<#nbsp;><#nbsp;>chsh사용자의 로그인 셸을 변경하는 명령어.사용자가 기본 로그인 셸을 변경하려면 해당 명령어를 사용함.사용자가 Bash 셸을 기본으로 사용하고 있다가 csh로 변경하려면 chsh 명령어를 사용하여 변경할 수 있음예시) chsh -s /bin/csh-s : 새로운 로그인 셸을 지정할 때 사용하는 옵션<#nbsp;>[해설작성자 : 담주가시험인데새벽2시야..]<#nbsp;><#nbsp;>/etc/shells : 사용할 수 있는 셸 확인 가능명령어 chsh 사용시chsh -l 옵션 = /etc/shells와 동일한 기능을 함<#nbsp;>[해설작성자 : 쏘니]<#nbsp;><#nbsp;>
