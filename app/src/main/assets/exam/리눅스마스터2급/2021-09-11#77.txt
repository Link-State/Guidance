문제지문 : 다음 중 X 서버에 IP 주소가 192.168.5.13 인 X 클라이언트의 접근을 허가하는 명령어로 알맞은 것은?
사진 : 
1번 : xhost + 192.168.5.13
2번 : xhost add 192.168.5.13
3번 : xauth + 192.168.5.13
4번 : xauth add 192.168.5.13
정답 : 1
해설 : xhost- IP나 도메인명을 이용해서 서버 접속 요청- 형식: xhost [+][-][ip|도메인명]xauth- .Xauthority 파일의 쿠키 내용을 추가, 삭제, 리스트를 출력하는 유틸리티- 형식: xauth [옵션]<#nbsp;>[해설작성자 : comcbt.com 이용자]<#nbsp;><#nbsp;>
