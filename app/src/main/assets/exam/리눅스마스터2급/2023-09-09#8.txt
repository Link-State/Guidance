문제지문 : 다음 설명에 해당하는 파일명으로 알맞은 것은?
사진 : <!PICTURE@image5>
1번 : /etc/fstab
2번 : /etc/mtab
3번 : /etc/mounts
4번 : /etc/partitions
정답 : 1
해설 : /etc/fstab -> 파일 시스템 테이블파일, 부팅 시 시스템이 어떤 파일 시스템들을 어떤 디렉터리에 마운트 해야하는지 정의/etc/mtab -> 시스템에 마운트 된 파일 시스템이나 디바이스의 정보를 알 수 있도록 한 파일/etc/mounts -> 존재하지 않는 디렉터리/proc/mounts -> 시스템 커널 기준의 실시간 마운트 정보/etc/partitions -> 잘못된 디렉터리/proc/partitions -> 커널이 인식한 파티션의 정보를 표시<#nbsp;>[해설작성자 : 1]<#nbsp;><#nbsp;>
