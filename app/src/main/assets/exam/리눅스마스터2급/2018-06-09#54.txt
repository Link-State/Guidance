문제지문 : 다음 중 X 윈도를 부팅 시에 실행하기 위해 설정하는 파일로 알맞은 것은?
사진 : 
1번 : /etc/fstab
2번 : /etc/x.org
3번 : /etc/inittab
4번 : /etc/initdefault
정답 : 4
해설 : /etc/fstab -> 마운트 가능한 사용자에 대해 파일 시스템을 지정/etc/x.org -> 기본적으로 리눅스에서 사용되는 X 윈도우 시스템/etc/inittab -> 부팅 시에 실행하기 위해 설정하는 파일/etc/initdefault -> init 프로세스의 설정 파일<#nbsp;>[해설작성자 : 0수생]<#nbsp;><#nbsp;>
