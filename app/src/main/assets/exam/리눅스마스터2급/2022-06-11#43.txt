문제지문 : 다음은 data 디렉터리의 하위 디렉터리를 포함해서 디렉터리 내부의 모든 파일 및 디렉터리의 그룹 소유권을 kait로 변경하는 과정이다. ( 괄호 ) 안에 들어갈 내용으로 알맞은 것은?
사진 : <!PICTURE@image14>
1번 : ㉠ chown, ㉡ -r
2번 : ㉠ chown, ㉡ -R
3번 : ㉠ chgrp, ㉡ -r
4번 : ㉠ chgrp, ㉡ -R
정답 : 8
해설 : (ㄱ) 해설 :chown은 파일이나 디렉터리의 사용자 소유권 및 그룹 소유권을 변경하는 명령어- 기본 형식 : # chown [옵션] [사용자명].[그룹명] [파일/디렉터리명]chgrp은 파일이나 디렉터리의 그룹 소유권을 변경하는 명령어- 기본 형식 : # chgrp [옵션] [그룹명] [파일/디렉터리명]이때 보기에는 kait라는 그룹명만 적혀있기 때문에 chown을 사용하는 경우, kait라는 사용자의 소유권을 변경하게 되므로, chgrp을 사용해야한다.(ㄴ) 해설 :-R : 하위 디렉터리를 포함한 모든 파일과 디렉터리의 그룹 소유권(chown의 경우 사용자 소유권)을 변경<#nbsp;>[해설작성자 : JSC]<#nbsp;><#nbsp;>
