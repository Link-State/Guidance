문제지문 : 리눅스에서 프린터 연결 선택 방법 중 설명이 틀린 것은?
사진 : 
1번 : JetDirect : TCP/IP 포트로 접속하는 Socket API방식이며 간단한 Job 전송 프로토콜이다.
2번 : Samba Printer : 윈도우즈 95/98/NT/XP등에 프린터가 공유 되어 있을때 사용가능하다.
3번 : Local : 리눅스 시스템에 프린터가 직접 설치되어 있을 경우이다.
4번 : Unix Printer : 프린터가 랜 환경에서 사용되는 다른 컴퓨터에 연결되어 있지 않은 경우 선택하는 옵션이다.
