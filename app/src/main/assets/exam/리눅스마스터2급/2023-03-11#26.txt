문제지문 : 프로세스 아이디(PID)가 1222인 bash 프로세스의 우선순위(NI)값이 0이다. 다음 중 이 프로세스의 NI값을 10으로 우선순위를 변경하는 명령으로 알맞은 것은?
사진 : 
1번 : nice 10 1222
2번 : nice -10 1222
3번 : nice 10 bash
4번 : nice -10 bash
정답 : 8
해설 : nice는 프로세스 명을 사용하여 우선순위를 조정한다우선순위를 n으로 하고 싶다면 nice -n 프로세스명 형식으로 입력하면 된다<#nbsp;>[해설작성자 : 발로푼다]<#nbsp;><#nbsp;>양수는 -n음수는 --n<#nbsp;>[해설작성자 : 빠대비]<#nbsp;><#nbsp;>위 해설에서 [우선순위를 n으로 하고 싶은 경우] 부분이 renice 와 혼동이 되어 보강하자면,본 문제에서는 프로세스 NI 값이 0 으로 기 제시되었기 때문에 nice -10 bash 로 NI값이 10이 되는 것임.단순히 NI 10을 만드는 것은 renice 10 1222 으로 가능.<#nbsp;>[해설작성자 : 오늘시험임]<#nbsp;><#nbsp;>nice,killall = 프로세스 명renice,kill = PIDnice는 새로운 프로세스 실행시 초기 운선순위 설정renice는 이미 실행중인 프로세스의 우선순위 변경<#nbsp;>[해설작성자 : Linux 고수가 될꺼야!]<#nbsp;><#nbsp;>아래와 같은 오류 신고가 있었습니다.여러분들의 많은 의견 부탁 드립니다.추후 여러분들의 의견을 반영하여 정답을 수정하도록 하겠습니다.참고로 정답 변경은 오류 신고 5회 이상일 경우 수정합니다.[오류 신고 내용]이미 실행 중인 프로세스(PID=1222)의 NI 변경 → renice 사용renice -n 10 -p 1222nice는 새 프로세스를 실행할 때만 NI 지정 가능하므로, 문제 지문과 딱 맞는 답은 없음.보기에서 골라야 한다면nice 10 1222 -> X (PID에 적용 불가)nice -10 1222 -> X (PID에 적용 불가)nice 10 bash -> X (NI=10)nice -10 bash -> X (NI=-10, 게다가 문제 요구는 10인데 -10임)보기에 정답이 없는게 아닌지?<#nbsp;>[해설작성자 : hyun]<#nbsp;><#nbsp;>
