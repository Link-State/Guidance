문제지문 : 다음은 사용자가 로그인 셸을 변경하는 과정이다. ( 괄호 ) 안에 들어갈 옵션으로 알맞은 것은?
사진 : <!PICTURE@image7>
1번 : -c
2번 : -l
3번 : -s
4번 : -u
정답 : 4
해설 : [chsh = change shell]1. -c : 없는 옵션입니다.2. -l : (list) chsh -l을 입력했을 경우 변경 가능한 쉘을 출력합니다.3. -s : (shell) 로그인 쉘을 사용자가 입력한 쉘로 변경합니다.4. -u : (help) chsh 명령어에 관한 도움말을 출력합니다.<#nbsp;>[해설작성자 : 합격기원1000]<#nbsp;><#nbsp;>
