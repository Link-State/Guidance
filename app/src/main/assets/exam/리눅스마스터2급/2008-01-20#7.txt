문제지문 : 다음 중 리눅스 파일 시스템의 종류와 그에 대한 설명으로 틀린 것은?
사진 : 
1번 : minix : 과거 minix에서 사용되어졌던 파일 시스템으로 가장 오래되고 기본이 되는 파일 시스템이다.
2번 : msdos : MS-DOS의 FAT 파일시스템과 호환을 지원하는 파일 시스템이다.
3번 : umsdos : MS-DOS 파일 시스템을 리눅스상에서도 긴 파일과 소유자, 접근허가, 링크와 장치 파일등을 사용할 수 있도록 확장한 시스템 이다.
4번 : hpfs OS/2 : minix의 제한이었던 파일이름과 파일시스템에 대한 제한을 보완한 minix 파일 시스템의 수정버전이다.
