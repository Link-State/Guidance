문제지문 : 다음 중 PID가 1109인 프로세스를 종료하기 위한 명령어로 틀린 것은?
사진 : 
1번 : kill -TERM 1109
2번 : kill -15 1109
3번 : killall -v -9 1109
4번 : kill -s SIGTERM 1109
정답 : 4
해설 : -TERM, -15, -s SIGTERM 모두 동일한 옵션       SIGHUP(HUP) <1> : 로그아웃, 설정 파일 다시 읽기       SIGINT(INT) <2> : 키보드에 의한 실행 중지, CTRL + C       SIGKILL(KILL) <9> : 강제 종료, emergency kill       SIGTERM(TERM) <15> : 실행 종료, 안전한 종료       SIGSTOP(STOP) <19> : 실행 정지, CTRZ + Zkillall : 프로그램 이름을 이용하여 특정 프로세스를 '한번에 종료'-v : 프로세스 종료 진행현황 확인 옵션<#nbsp;>[해설작성자 : 이번주 시험...]<#nbsp;><#nbsp;>killall 명령어는 1109가 아니라 프로세스 명으로 작성해야하기 때문에 틀렸으므로 3번이 답입니다.<#nbsp;>[해설작성자 : comcbt.com 이용자]<#nbsp;><#nbsp;>
