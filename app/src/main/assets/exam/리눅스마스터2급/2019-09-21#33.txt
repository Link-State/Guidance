문제지문 : 다음 중 emacs 에디터에서 사용되는 커서 이동 명령으로 틀린 것은?
사진 : 
1번 : [Ctrl] + [C]
2번 : [Ctrl] + [P]
3번 : [Ctrl] + [F]
4번 : [Ctrl] + [N]
정답 : 1
해설 : Ctrl + C : 편집 종료Ctrl + P : 커서를 한 줄 위로 이동Ctrl + F : 커서를 오른쪽으로 이동Ctrl + N : 커서를 한 줄 아래로 이동<#nbsp;>[해설작성자 : 한백고 개구리]<#nbsp;><#nbsp;>
