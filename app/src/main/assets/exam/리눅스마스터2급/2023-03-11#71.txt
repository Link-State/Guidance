문제지문 : 다음 중 SSH와 관련된 서비스로 가장 거리가 먼 것은?
사진 : 
1번 : nfs
2번 : scp
3번 : rsh
4번 : sftp
정답 : 1
해설 : NFS : 네트워크 파일 시스템SCP : SSH 기반의 원격 파일 전송 프로토콜RSH : 원격 명령을 실행하는 프로토콜 SSH로 대체됨SFTP : SSH 파일 전송 프로토콜 FTP의 SSH버전RSH가 SSH보다 보안성이 떨어지는 프로토콜로만 외우고 있어서 정답이라고 생각했는데SHH로 대체되었다는 점에서 관련이 있다고 한 것 같습니다.<#nbsp;>[해설작성자 : comcbt.com 이용자]<#nbsp;><#nbsp;>
