문제지문 : 다음 중 시스템 시작 시 X 윈도 모드로 부팅이 되도록 설정하는 명령은?
사진 : 
1번 : systemctl runlevel.5
2번 : systemctl graphical.target
3번 : systemctl set-default runlevel.5
4번 : systemctl set-default graphical.target
정답 : 8
해설 : * systemctl set-default 명령은 시스템의 기본 실행 레벨을 설정합니다.* graphical.target은 그래픽 환경으로서, X 윈도 모드로 부팅될 때 사용되는 실행 레벨을 나타냅니다.따라서 답은 4번이 맞습니다..systemctl set-default graphical.target 명령을 실행하면 시스템은 다음 부팅 때부터 X 윈도 모드로 기동됩니다.<#nbsp;>[해설작성자 : 양희찬]<#nbsp;><#nbsp;>3번이 답이 안되는 이유는 systemctl set-default runlevel.5 가아닌systemctl set-default runlevel5 가 맞기 때문systemctl set-default runlevel3 는 CLI<#nbsp;>[해설작성자 : 해삼말미잘]<#nbsp;><#nbsp;>
