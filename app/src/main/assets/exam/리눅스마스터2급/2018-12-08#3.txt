문제지문 : 다음중 리눅스파일시스템에 대한설명으로틀린 것은?
사진 : 
1번 : Reiserfs, XFS, JFS는 저널링 파일 시스템이다.
2번 : sysv는 리눅스에서 사용하는 가상 파일 시스템이다.
3번 : iso9660은 DVD를 마운트할 때 지정하는 파일 시스템이다.
4번 : nfs는 네트워크 상의 시스템 파일을 공유할 때 사용하는 파일 시스템이다.
정답 : 2
해설 : ++ 2. 유닉스 시스템 V(UNIX System V) 또는 간단히 SysV는 유닉스 운영 체제의 최초 상용 버전 가운데 하나이다..원래 AT&T가 개발하였다가 1983년에 처음 출시하였다..시스템 V의 4가지 주된 버전이 "릴리즈 1, 2, 3, 4"라는 이름으로 출시되었다..시스템 V 릴리즈 4, 곧 SVR4는 상업적으로 가장 성공한 버전이 되었다.<#nbsp;>[해설작성자 : 너구리는 라쿤]<#nbsp;><#nbsp;>
