문제지문 : 다음 중 tar 명령의 옵션에 대한 설명으로 틀린 것은?
사진 : 
1번 : -p : 모든 퍼미션 정보를 유지한다.
2번 : -f : 처리 과정을 자세히 보여준다.
3번 : -c : 새 저장 파일을 만든다.
4번 : -m : 파일의 변경 시간정보를 유지하지 않는다.
정답 : 2
해설 : -p : tar파일을 생성 또는 풀때 원본 퍼미션정보를 유지-f : tar파일을 사용할때 사용-c : tar파일을 생성할때 사용-m : 파일의 시간정보를 유지하지 않음-t : tar파일의 내용을 확인할때 사용-v : tar파일을 생성하거나 풀때 과정 보기<#nbsp;>[해설작성자 : 황상연]<#nbsp;><#nbsp;>-f : 추가로 정확히 설명하자면, 압축할 때나 해제시 파일명을 지정할 때 사용합니다.<#nbsp;>[해설작성자 : 비트코인 가즈앙]<#nbsp;><#nbsp;>
