문제지문 : 다음 중 로그인 셸을 확인하는 명령으로 알맞은 것은?
사진 : 
1번 : cat SHELL
2번 : cat $SHELL
3번 : echo SHELL
4번 : echo $SHELL
정답 : 8
해설 : echo 명령어는 출력해주는 명령어SHELL 이라는 환경변수에는 사용자의 로그인 쉘이 저장되어있다.<#nbsp;>[해설작성자 : 리눅쓰]<#nbsp;><#nbsp;>cat는 파일의 내용을 출력하는 명령어입니다.cat $SHELL 명령어를 실행하면 $SHELL 변수에 저장된 셸 경로를 파일 이름으로 처리하고 해당 파일의 내용을 출력하려고 시도하겠지만 $SHELL은 파일 명이 아니라, 환경 변수이므로 파일이 없다는 오류가 발생echo는 환경 변수의 값을 표시하는 명령어$이 있어야 변수라는 것을 인식할 수 있음.<#nbsp;>[해설작성자 : 합격가자]<#nbsp;><#nbsp;>
