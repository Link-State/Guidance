문제지문 : 다음 중 네트워크 관련 파일과 설명이 틀린 것은?
사진 : 
1번 : /etc/resolv.conf : 네임 서버(DNS 서버)를 설정하는 파일
2번 : /etc/services : 각 응용프로그램 및 프로토콜에 할당될 포트를 관리하는 파일
3번 : /etc/hosts : IP주소와 호스트명을 매핑 시켜 데이터베이스처럼 사용하는 파일
4번 : /etc/sysconfig/network : 네트워크 인터페이스 환경 설정과 관련된 파일들이 저장되어 있는 파일
