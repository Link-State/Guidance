문제지문 : 다음 중 vi 편집기의 개발 순서로 알맞은 것은?
사진 : 
1번 : gVim → vi → vim
2번 : vim → gVim → vi
3번 : vim → vi → gVim
4번 : vi → vim → gVim
정답 : 8
해설 : vi는 텍스트 기반의 편집기다.vim은 텍스트 기반이 맞긴한데 뭔가 여러가지 색깔들이 있다.gvim은 그래픽 기반의 편집기다 gedit랑 비슷하다고 보면 될듯?한번씩 파일을 열어보면 vi -> vim -> gvim 이렇게 된다는것을 알수있을것이다.<#nbsp;>[해설작성자 : 행복히오스]<#nbsp;><#nbsp;>
