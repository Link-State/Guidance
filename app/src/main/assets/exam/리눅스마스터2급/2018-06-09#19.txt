문제지문 : 다음 중 웹서버 데몬을 구동하는 방법이 아닌 것은?
사진 : 
1번 : service httpd start
2번 : /etc/rc.d/httpd start
3번 : /etc/init.d/httpd restart
4번 : /etc/rc.d/init.d/httpd restart
정답 : 2
해설 : /etc/rc.d : 부팅 레벨별 부팅 스크립트 파일이 저장된 디렉토리/etc/rc.d/init.d : 시스템 초기화 파일들이 저장된 디렉토리<#nbsp;>[해설작성자 : 모르겠다]<#nbsp;><#nbsp;>웹서버 데몬을 구동하는 방법은 'service 서비스명 실행옵션'과 '/etc/init.d/서비스명 [실행옵션]'이다.<#nbsp;>[해설작성자 : 오홍]<#nbsp;><#nbsp;>
