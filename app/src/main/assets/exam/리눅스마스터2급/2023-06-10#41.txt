문제지문 : 다음 중 rpm 명령의 설치 관련 옵션으로 가장 거리가 먼 것은?
사진 : 
1번 : -i
2번 : -U
3번 : -F
4번 : -f
정답 : 8
해설 : -i =  install 패키지 설치-U = upgrade 패키지 업그레이드-F = freshen 패키지 업그레이드 또는 설치-f <- 이런 명령 없음<#nbsp;>[해설작성자 : 합격 ㄱ]<#nbsp;><#nbsp;>rpm 명령어에서 -f 옵션은 단독으로 사용할 수 없지만, 파일을 지정하는데 사용함.예를 들어 다음과 같이 -q 옵션(query 옵션)과 함께 사용할 수 있음.rpm -qf /path/to/file이런식으로 사용하면 해당 경로에 있는 파일을 소유하고 있는 패키지를 찾을 수 있음.<#nbsp;>[해설작성자 : 빠대비]<#nbsp;><#nbsp;>
