문제지문 : 다음 중 emacs에디터의 키 조합 설명으로 틀린 것은?
사진 : 
1번 : [Alt] + [d] : 커서가 위치한 부분부터 단어를 삭제
2번 : [Alt] + [k] : 커서가 위치한 부분부터 문장 전체를 삭제
3번 : [Ctrl] + [f] : 현재 커서가 위치한 줄의 화면 아래로 이동
4번 : [Ctrl] + [a] : 현재 커서가 위치한 줄의 처음으로 커서를 이동
정답 : 4
해설 : ctrl N 현재 커서를 한 줄 아래로 이동<#nbsp;>[해설작성자 : kimpo 사이버보안]<#nbsp;><#nbsp;>
