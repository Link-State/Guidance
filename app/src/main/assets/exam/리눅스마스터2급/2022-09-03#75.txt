문제지문 : 다음 중 GNOME과 가장 관련이 깊은 라이브러리로 알맞은 것은?
사진 : 
1번 : Qt
2번 : Xlib
3번 : XCB
4번 : GTK+
정답 : 8
해설 : Qt는 컴퓨터 프로그래밍에서 GUI 프로그램 개발에 널리 쓰이는 크로스 플랫폼 프레임워크Xlib은 1985년 즈음에 출현했으며 현재 수많은 유닉스 계열 운영 체제의 GUI에 사용XCB(X protocol C-language Binding)는 컴퓨팅에서 X 윈도 시스템을 위한 C 언어 결합GTK는 김프 툴킷(GIMP Toolkit)의 준말로, 초기에 김프를 위해서 만든 툴킷이었으며 X 윈도 시스템을 위한 위젯 툴킷 가운데 하나GNU Network Object Model Environment, GNOME은 데스크톱 프로그램 집합의 일종이기도 하며 이를 개발하는 프로젝트의 이름이기도 하다.따라서 GNU 내부에 있는 GIMP 내부 GTK 라이브러리로 연관되어있다.<#nbsp;>[해설작성자 : Jin]<#nbsp;><#nbsp;>데스크탑 환경 : 라이브러리GNOME : GTK+Xfce : GTK+KDE : Qt잘모르는 데스크탑 환경 나오면 대부분 GTK+ 라이브러리 사용함.<#nbsp;>[해설작성자 : 빠대비]<#nbsp;><#nbsp;>
