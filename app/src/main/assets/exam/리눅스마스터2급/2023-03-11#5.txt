문제지문 : 다음은 ihduser 사용자에게 대한 디스크 쿼터 설정하는 과정이다. ( 괄호 ) 안에 들어갈 명령어로 알맞은 것은?
사진 : <!PICTURE@image3>
1번 : quota
2번 : edquota
3번 : setquota
4번 : xfs_quota
정답 : 2
해설 : 디스크 쿼터 설정 명령은 edquota나 setquota 이다edquota [옵션] 사용자 형식으로 사용 가능하지만setquota는 edquota보다 인자가 많이 필요하다setquota의 사용 방법을 알고 있으나 여백이 부족하여 이를 적지 않는다<#nbsp;>[해설작성자 : 발로푼다]<#nbsp;><#nbsp;>quota: 사용자나 그룹의 디스크 사용량과 할당량(쿼터)을 보여줌.edquota: 텍스트 에디터와 같은 환경에서 쿼터를 편집할 수 있게 해줌.setquota: 명령줄에서 직접 쿼터를 설정하거나 수정하기 위해 사용.(보통 -u 옵션 사용하면 이거임.)xfs_quota: XFS 파일 시스템에서 쿼터를 명령줄에서 설정함.(보통 -x -c 옵션 사용하면 이거임.)<#nbsp;>[해설작성자 : 빠대비]<#nbsp;><#nbsp;>
