해설 : Token Ring:토큰을 사용하여 데이터 충돌 방지, 링 토폴로지 사용.주로 소규모 네트워크에서 사용.FDDI (Fiber Distributed Data Interface):광섬유 케이블 사용, 이중 링 구조, 100Mbps의 속도.대규모 네트워크에서 고속 데이터 통신.X.25:패킷 스위칭 네트워크, 공공 전화망에서 사용, 신뢰성 있는 데이터 전송.WAN 연결, 인터넷 이전의 데이터 통신.Ethernet:MAC 주소 기반 통신, UTP/BNC 케이블 사용, 허브/스위치 사용.가장 널리 사용되는 네트워크 기술, 대부분의 LAN에서 사용.<#nbsp;>[해설작성자 : 날릴수없는4만4처넌]<#nbsp;><#nbsp;>
