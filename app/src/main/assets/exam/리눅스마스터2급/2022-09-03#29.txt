문제지문 : 다음 중 cron을 이용해서 매주 1회만 작업 스크립트를 실행하려고 할 때 ( 괄호 ) 안에 들어갈 내용을 알맞은 것은?
사진 : <!PICTURE@image12>
1번 : 4 0 * 1 *
2번 : 4 0 1 * *
3번 : 4 0 * * 2
4번 : 4 0 * 2 *
정답 : 4
해설 : crontab은 7개 필드로 구성되는데요.앞의 4개 필드는 작은 단위에서 커진다고 보면 편합니다.1분 < 1시간 < 1일 < 1달     =>  분 / 시간 / 일 / 달5번째 필드는 요일입니다..(월요일[1]부터 일요일[7 or 0]까지)따라서, "매주 ?요일"이라고 할 수 있는 건 3번뿐입니다.<#nbsp;>[해설작성자 : 두번당하지말자]<#nbsp;><#nbsp;>
