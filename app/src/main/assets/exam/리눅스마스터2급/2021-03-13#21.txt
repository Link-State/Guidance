문제지문 : 다음 명령 실행 시에 발생되는 시그널로 알맞은 것은?
사진 : <!PICTURE@image11>
1번 : SIGHUP
2번 : SIGKILL
3번 : SIGINIT
4번 : SIGTERM
정답 : 8
해설 : kill 명령어에서 옵션 생략시 기본값이 SIGTERM(15)입니다..문제에서 kill 2101 = kill (-옵션 : 생략) 2101(PID)을 말하며 옵션이 생략되었으므로 정답은 4번.kill -옵션 PID<#nbsp;>[해설작성자 : 멀쩡한 문제!]<#nbsp;><#nbsp;>SIGHUP : 1SIGKILL : 9SIGINT :2SIGTERM : 15는 프로세스가 어떻게 동작 할건지에 대한 명령 신호를 보내는 명령어 kill 뒤에 붙는 옵션들을 번호로 할당한 거예요.kill [옵션][프로세스번호]kill 2101이면 2101의 번호가 할당된 프로세스를 종료하라는 뜻입니다.kill 뒤에 옵션이 아무것도 안 붙는다면, default 값인 SIGTERM : 15(종료)가 동작합니다.욥션 사용 예) kill -9 2101 => 강제 종료의 신호를 2101 프로세스로 보내라는 뜻입니다..=> 강제 종료의 동작 수행 : SIGKILL<#nbsp;>[해설작성자 : comcbt.com 이용자]<#nbsp;><#nbsp;>
