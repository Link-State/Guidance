문제지문 : 다음 중 IPv4의 C클래스 대역에 할당된 사설 IP 주소의 네트워크 개수로 알맞은 것은?
사진 : 
1번 : 32
2번 : 64
3번 : 128
4번 : 256
정답 : 8
해설 : C class 사설 IP 대역= 192.168.0.0 ~ 192.168.255.255네트워크 개수는 총 255 + 1개 = 256개<#nbsp;>[해설작성자 : 새우깡]<#nbsp;><#nbsp;>* 네트워크 개수 구체적 설명:192.168.0.0/24부터 192.168.255.0/24까지 각기 다른 256개의 /24 네트워크가 있습니다.각 네트워크의 범위는 다음과 같습니다:  * 192.168.0.0/24 → 192.168.0.0 ~ 192.168.0.255 (1개의 네트워크)  * 192.168.1.0/24 → 192.168.1.0 ~ 192.168.1.255 (1개의 네트워크)  * ...  * 192.168.255.0/24 → 192.168.255.0 ~ 192.168.255.255 (1개의 네트워크)이런 식으로, 192.168.0.0부터 192.168.255.255까지 '총 256개'의 /24 네트워크가 있습니다.<#nbsp;>[해설작성자 : 찰떡]<#nbsp;><#nbsp;>
