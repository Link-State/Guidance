문제지문 : 다음 IPv4의 C 클래스 대역에 할당된 사설 IP 주소의 네트워크 개수로 알맞은 것은?
사진 : 
1번 : 1
2번 : 16
3번 : 192
4번 : 256
정답 : 8
해설 : 사설IP 와 넷마스크를 잘 구분해야함 A,B 클래스의 경우 답이 다름.사설 IP 주소내역A = 10.0.0.0 ~ 10.255.255.255 = 1개 네트워크B = 172.16.0.0 ~ 172.31.255.255 = 16개 네트워크C = 192.168.0.0 ~ 192.168.255.255 = 256개 네트워크<#nbsp;>[해설작성자 : 성수SO]<#nbsp;><#nbsp;>*추가) 서브넷 마스크의 경우IPv4의 클래스는 A부터 E까지 있는데 보통 사용되는 A,B,C만 살펴보자면A = 256*256*256 = 16,777,214B = 256*256 = 65,536C = 256 개의 호스트주소를 사용할 수 있다..<#nbsp;>[해설작성자 : 3일 남음 ]<#nbsp;><#nbsp;>
