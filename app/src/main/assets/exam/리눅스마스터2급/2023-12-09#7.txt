문제지문 : 다음 중 데비안 계열 리눅스에서 환경 설정 파일도 포함해서 vsftpd 패키지를 제거하는 명령으로 알맞은 것은?
사진 : 
1번 : apt-get purge vsftpd
2번 : apt-get remove vsftpd
3번 : apt-get erase vsftpd
4번 : apt-get delete vsftpd
정답 : 1
해설 : 환경설정까지 삭제 = purge<#nbsp;>[해설작성자 : 5일벼락치기로합격]<#nbsp;><#nbsp;>remove: 패키지 제거<#nbsp;>[해설작성자 : 합격]<#nbsp;><#nbsp;>purge = 환경설정까지 다 지움remove = remove랑 erase는 동일한 기능 수행. 환경설정파일은 남겨둠.erase = removedelete = 유효하지 않은 명령어<#nbsp;>[해설작성자 : 자격증 사냥꾼]<#nbsp;><#nbsp;>apt-get purge vsftpd: 패키지와 환경 설정 파일까지 제거. (정답)apt-get remove vsftpd: 패키지만 제거, 환경 설정 파일은 유지.APT는 데비안 계열 리눅스의 핵심 패키지 관리 도구로, 설치/제거 옵션을 적절히 선택하는 것이 중요합니다.<#nbsp;>[해설작성자 : 민규]<#nbsp;><#nbsp;>
