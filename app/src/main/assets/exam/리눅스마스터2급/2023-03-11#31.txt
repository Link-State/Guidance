문제지문 : 다음 중 X 윈도 환경에서만 실행되는 편집기로 알맞은 것은?
사진 : 
1번 : gedit
2번 : pico
3번 : nano
4번 : emacs
정답 : 1
해설 : ① gedit : X윈도 시스템 환경에서 사용할 수 있는 오픈 소스 텍스트 편집기② pico : 아보일 카사르가 개발한 텍스트 편집기로 초기 리눅스 배포판에서 사용한 편집기로 무료이지만, 오픈소스 라이선스가 아니므로 소스 수정이 불가능하다.③ nano : GNU프로젝트에서 'pico' 편집기 복제판인 'nano'편집기를 개발하였다④ emacs : 리차드 스톨만이 개발하였으며, 이후 제임스 고슬링이 LISP 언어를 기반으로 'emacs'에 다양한 기능을 추가했다.<#nbsp;>[해설작성자 : 리눅스 마스터 한방에 합격하자 ]<#nbsp;><#nbsp;>X윈도 환경 편집기: kwrite, gedit<#nbsp;>[해설작성자 : 찰떡]<#nbsp;><#nbsp;>
