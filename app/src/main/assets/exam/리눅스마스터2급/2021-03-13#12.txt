문제지문 : 다음 중 bash에서 os라는 셸 변수에 linux라는 값을 선언하는 방법으로 알맞은 것은?
사진 : 
1번 : os=linux
2번 : set os=linux
3번 : unset os=linux
4번 : env os=linux
정답 : 1
해설 : 셸 변수는 특정한 셸에서만 적용되는 변수를 말함.리눅스에서는 명령행에서 '변수명 = 값' 형태로 지정하여 사용 가능.변수값을 출력할 때는 변수명 앞에 $를 붙여서 echo 명령으로 확인 가능<#nbsp;>[해설작성자 : 말랑모찌롱]<#nbsp;><#nbsp;>
