기출연도 : 2019-06-15
과목 : 1
문제번호 : 26
문제지문 : 다음 중 프로세스 증가 없이 우선순위를 조정할 때 사용하는 명령으로 알맞은 것은?
사진 : 
1번 : nice
2번 : cron
3번 : nohup
4번 : renice
정답 : 8
해설 : nice : 초기 설정된 작업의 우선순위를 변경(프로세스를 새로 생성하는 경우)renice : 이미 실행되고 있는 프로세스의 우선순위를 변경문제에서 프로세스 증가 =  프로세스 생성으로 이해하면 될 것 같습니다.<#nbsp;>[해설작성자 : 문제 지문좀 명확하게 내줬으면 하네요]<#nbsp;><#nbsp;>기존 NI값에서 증가 감소 시키는건 nice, 아예 새로 설정하는건 renice로 외우시면 되겠습니다..더불어 nice는 프로세스명, renice는 PID번호.<#nbsp;>[해설작성자 : 자격증 사냥꾼]<#nbsp;><#nbsp;>예를 들어 bash라는 프로세스가 있다고 합시다..bash의 PID가 1222이고 NI는 10이라고 합시다.nice -10 bash하면 PID가 1223이라는 새로운 bash 프로세스가 생성되고 새로 생성된 bash의 NI값이 10이 되는겁니다.반면 renice 10 1222하면 새로운 프로세스 생성 없이 기존 PID 1222의 bash의 NI가 10이 된다는 의미입니다.프로세스 증가도 맞지만 프로세스 생성 없이라는 표현이 좀 더 깔끔한 문장 같습니다..다회의 리눅스 기출문제를 풀어보면서느낀건, 일부 출제문제들의 국어의 문법적 부실함이 보이는게 더러 있더라구요.
