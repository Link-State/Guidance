문제지문 : 다음은 lin.sh 파일의소유자는 ihduser, 소유 그룹은 kaitgroup으로 지정하는 과정이다. ( 괄호 ) 안에 들어갈 명령으로 알맞은 것은?
사진 : <!PICTURE@image24>
1번 : chmod
2번 : chown
3번 : chgrp
4번 : umask
정답 : 2
해설 : 1.  chmod : 허가권과 관련한 명령어. 소유자(owner): u, 그룹(group): g, 기타 사용자(others 혹은 public): o, 모든 사용자: a            옵션 ‘-R’: 하위 디렉터리 포함2.  chown : 소유권과 관련한 명령어. chown [옵션][:그룹명] 파일명’:그룹명 앞에 콜론(:)을 붙여 사용자 소유권, 그룹 소유권분리3.  chgrp : -h 심볼릭링크 파일 그룹 소유권 변경4.  umask : 파일이나 디렉터리의 생성시 부여되는 기본 허가권의 값을 지정            옵션 ‘-S’: umask 값을 u,g,o와 w,r,x와 같은 문자로 나타냄            기본권한: 파일(666), 디렉터리(777)<#nbsp;>[해설작성자 : 해설을 보세요]<#nbsp;><#nbsp;>
