문제지문 : chmod에서 모드 표기는 3자리 8진수인데 특수 목적 접근 모드를 위해 8진수 하나를 더 추가하여 4자리 8진수로 표현하는 경우도 있는데 다음 중 특수 목적 접근 모드에 대한 설명으로 틀린 것은?
사진 : 
1번 : 1000은 sticky bit이다.
2번 : 2000은 SetGID 비트로 프로세스 실행시 GID 즉 Group ID, 그룹의 ID 를 설정하는 것이다.
3번 : 4000은 SetUID 비트로 프로세스 실행 시 UID 즉 User ID, 소유자의 ID 를 설정하는 것이다.
4번 : 특수목적 접근 모드는 root 사용자만 설정할 수 있다.
