문제지문 : 다음 중 특정 사용자의 ~/.bashrc 파일에 설정하는 항목으로 가장 알맞은 것은?
사진 : 
1번 : 프롬프트와 function
2번 : alias와 프롬프트
3번 : alias와 function
4번 : 프롬프트와 PATH
정답 : 4
해설 : ~/.bashrc는 별칭(alias)과 bash가 수행될 때 실행되는 함수를 제어하는 지역적인 시스템 설정과 관련된 파일이다.이들 별칭과 함수들은 오직 해당 사용자에게만 한정되며, 그 이외의 다른 사용자에게는 영향을 미치지 않는다..<#nbsp;>[해설작성자 : 동그리]<#nbsp;><#nbsp;>개인 사용자가 alias, function을 일시적으로 사용가능하면 다음 로그인 시 적용되지 않음.따라서 지속적으로 적용하기 위해서는 관련 설정파일에 설정할 것.~/.bashrc: 개인 사용자가 정의하는 alias, function이 있는 파일~/.bash_profile: 개인 사용자의 시작 프로그램 설정, 환경설정과 관련있는 파일사용자가 로그인 함 -> ~/.bash_profile 파일을 불러들임~/.bash_logout: 개인 사용자가 로그아웃을 수행하는 설정을 지정하는 파일<#nbsp;>[해설작성자 : 카구야]<#nbsp;><#nbsp;>
