문제지문 : 다음 중 OSI 7계층 모델을 상위 계층부터 나열한 순서로 알맞은 것은?
사진 : 
1번 : 물리 → 데이터링크 → 네트워크 → 전송→ 세션 → 표현 → 응용
2번 : 응용 → 표현 → 세션 → 전송 → 네트워크→ 데이터링크 → 물리
3번 : 응용 → 세션 → 표현 → 전송 → 네트워크→ 데이터링크 → 물리
4번 : 물리 → 데이터링크 → 네트워크 → 전송→ 표현 → 세션 → 응용
정답 : 2
