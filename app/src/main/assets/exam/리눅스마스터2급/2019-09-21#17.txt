문제지문 : 다음 중 셸의 역할에 대한 설명으로 알맞은 것은?
사진 : 
1번 : 프로세스 스케줄링을 관리한다.
2번 : 실행중인 프로그램 관리 역할을 수행한다.
3번 : 사용자로부터 명령을 입력받아서 해석한다.
4번 : CPU, 메모리, 디스크 등의 하드웨어를 제어한다.
정답 : 4
해설 : (1)명령어 해석- 사용자가 명령어 입력-> (해석하여) 리눅스 전달 → 처리된 결과를 다시 사용자에게 전달(2)사용자가 시스템을 사용할 수 있는 환경을 설정(3)셸에서 운영되는 프로그램을 수행-셸은 사용자가 시스템을 사용하기 위한 초기 환경설정을 수행* 환경설정은 초기화 파일을 통해 이루어짐* 초기화 파일 : 파일을 검색하기 위한 경로, 파일이 생성될 때 부여되는 기본 권한, 기타 다양한 환경변수를 포함   → 사용자가 시스템 로그인하면 해당 사용자의 초기화 파일이 실행되어 환경설정이 이루어짐<#nbsp;>[해설작성자 : 추가적인 부분을 찾아왔습니다.]<#nbsp;><#nbsp;>
