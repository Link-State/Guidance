기출연도 : 2019-06-15
과목 : 1
문제번호 : 2
문제지문 : 다음 중 ihduser 사용자의 홈 디렉터리 총 사용량을 단위를 붙여서 출력하는 명령으로 알맞은 것은?
사진 : 
1번 : df -hT ~ihduser
2번 : df -sh ~ihduser
3번 : du -hT ~ihduser
4번 : du -sh ~ihduser
정답 : 8
해설 : df (diskfree) 리눅스 시스템 전체의 디스크 사용량을 표기.-h : 사람이 보기 편하게 용량 단위별 사용량 표기.-T : type. 파일시스템의 유형을 표기.du (diskusage) 특정 디렉토리에 대한 디스크 사용량을 표기.-h : 사람이 보기 편하게 용량 단위별 표기.-b,k,m : 바이트, 킬로바이트, 메가바이트 등 각 단위별 표기.-a : 디렉토리 내부의 각 파일 별 사용량을 표기.-s : 전체 사용량. 하위디렉토리를 보여주지 않음.
