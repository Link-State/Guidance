문제지문 : 부팅 과정의 순서로 알맞은 것은?
사진 : 
1번 : ROM BIOS → HDD의 MBR → 리눅스 커널 이미지 로딩 → init 실행
2번 : MBR → init 실행 → ROM BIOS → 커널 로딩
3번 : 커널 로딩 → init 실행 → ROM BIOS → MBR
4번 : init 실행 → ROM BIOS → MBR → 커널 로딩
정답 : 1
해설 : 자료의 부팅 순서는 ROM BIOS, HDD의 MBR, 리눅스 커널 이미지 로딩, init 실행이다.
