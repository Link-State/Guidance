문제지문 : 섀도 패스워드(Shadow Password)를 사용할 때, /etc/passwd 파일에 포함된 내용이 아닌 것은?
사진 : 
1번 : uid
2번 : gid
3번 : 패스워드
4번 : 로그인 셸
정답 : 4
해설 : shadow password 사용 시 /etc/passwd의 두 번째 필드에는 실제 암호 대신 x 같은 표시만 저장.<#nbsp;>① uid: 포함.<#nbsp;>② gid: 포함.<#nbsp;>③ 실제 패스워드: 포함되지 않음.<#nbsp;>④ 로그인 셸: 포함.
