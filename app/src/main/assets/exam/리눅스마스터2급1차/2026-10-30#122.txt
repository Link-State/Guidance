문제지문 : X Window System의 클라이언트-서버 구조에 대한 설명으로 옳은 것은 무엇인가?
사진 : 
1번 : 서버는 항상 원격 데이터베이스만 의미한다
2번 : X 서버는 화면 표시와 입력 장치를 관리하고 X 클라이언트는 표시 요청을 보낸다
3번 : X 클라이언트는 반드시 커널 내부에서만 실행된다
4번 : 클라이언트와 서버는 같은 컴퓨터에서만 동작할 수 있다
정답 : 2
해설 : X 시스템에서는 X 서버가 디스플레이·입력 장치를 관리하고 클라이언트가 화면 출력 등을 요청한다.
